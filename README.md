# Sherwin T. Ramirez | Personal Portfolio

A sleek, responsive, and professional personal portfolio website showcasing Front-End Development, UI/UX Design, and Game Development projects. 

## 🌐 Live Demo

You can host this portfolio on GitHub Pages. Once deployed, the live link will look like:
`https://sheerwiiin.github.io/Sherwin_portfolio/`

---

## 🚀 Features

- **About Me Section:** A high-level introduction of skills and focus areas.
- **Skills Showcase:** Highlighted expertise in Front-End Development, UI/UX Design, and Unity 2D Game Development.
- **Projects Gallery:**
  - **Game Development:** Embedded showcase videos of Unity projects (e.g., *Racoon Dash Guardian Falls*).
  - **Graphic Design:** A gallery of cropped-fit custom graphic t-shirt designs.
- **Interactive Navigation:** Smooth scrolling and a clean, responsive navigation bar.
- **Contact Form/Links:** Direct access to email, GitHub, and social profiles.

---

## 🛠️ Built With

- **HTML5:** Semantic markup for structure and SEO.
- **CSS3:** Modern styling, custom color palette, responsive layouts, and animations.
- **JavaScript:** Client-side interactivity and scrolling behaviors.

## 💻 Local Development

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/sheerwiiin/Sherwin_portfolio.git
   cd Sherwin_portfolio
   ```

2. **Open the project:**
   Simply open `index.html` in your favorite web browser, or use an extension like VS Code's **Live Server** to run it locally.

---

## 📦 Deployment to GitHub Pages

To make your portfolio live on GitHub Pages:

1. Push this repository to your GitHub account (see instructions below).
2. On GitHub, navigate to your repository settings.
3. In the left sidebar, click on **Pages** (under the "Code and automation" section).
4. Under **Build and deployment**, set the source to **Deploy from a branch**.
5. Select the **main** branch and `/ (root)` folder, then click **Save**.
6. Within a couple of minutes, your portfolio will be live at `https://sheerwiiin.github.io/Sherwin_portfolio/`!
